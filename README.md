# Retro Arcade

A simple browser-based arcade website with classic mini-games built using HTML, CSS, and JavaScript.

## Games Included

- Snake
- Pong
- Tic-Tac-Toe
- Call of Duty
- Voice Chat

## How to Run

Because this project is fully static, you can view it locally in a browser by opening `index.html` directly.

For a local web server, run:

```bash
python -m http.server 8000
```

Then open:

```text
http://localhost:8000
```

## Project Structure

- `index.html` — arcade home menu
- `snake.html` — Snake game
- `pong.html` — Pong game
- `tictactoe.html` — Tic-Tac-Toe game
- `callofduty.html` — shooter-style game
- `voicechat.html` — browser microphone voice chat demo

## Notes

This project is designed as a lightweight front-end demo and does not require any framework or installation steps.
